## Interactive "nearby causes" map (linked to "Quiero ayudar" feature)
Idea: show an interactive map with nearby real-world causes/charities so users feel their "want to help" activity has real local impact.

**Why deferred:** requires an external data source (NGO/charity API), content moderation, and precise geolocation to avoid feeling empty/fake if launched too early — especially before the app has a real user base. Building it before launch would also delay the more urgent Google Play production access work.

**How to apply:** revisit after the app has real users and has passed the Google Play production review. When picked back up, prefer a lightweight first version using existing data (e.g., show other users who also marked `wantToHelp`/`helpWith` nearby) instead of external causes data, to avoid an empty-feeling map.
